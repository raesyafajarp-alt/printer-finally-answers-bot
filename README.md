A deterministic program that drafts, scores, and picks the office printer's funniest comeback — one line, 1 to 240 characters, in the machine's own tired, literal, passive-aggressive voice — and writes it to `/output/entry.txt`. Each of the six candidate lines is scored against the five judge criteria (the printer's own voice, humour, machine-like tone, a comeback that lands in a single read, and freshness), and the winner is checked against the competition gate (UTF-8, 1–240 characters, a single line, not only whitespace) before it is written.

## Run it

```sh
python3 main.py
```
